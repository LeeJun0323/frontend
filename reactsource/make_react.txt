press r + enter to restart the server
press u + enter to show server url
press o + enter to open in browser
press c + enter to clear console
press q + enter to quit

(해당 프로젝트 폴더로 터미널을 들어간 뒤)
npm run dev : 작성하는 코드가 실시간으로 반영됨(개발시 사용)
    http://localhost:5173/

개발 종료 후 build
npm run build : 서버에 올려서 사용자들에게 웹페이지로 배포될 파일들로 코드를 모아 컴파일
dist 폴더 생성

npm run preview : build를 통해 나온 결과물을 테스트하는 단계
    http://localhost:4173/
